EARTIFY — نسخة العرض التجريبي على Vercel
========================================

المشروع جاهز للرفع على GitHub ثم ربطه بـ Vercel.

مهم جدًا بخصوص مفتاح OpenAI:
- المفتاح الذي أُرسل سابقًا في المحادثة يجب إلغاؤه فورًا من لوحة OpenAI؛ لا تستخدمه مرة أخرى.
- لم يتم وضع أي مفتاح API داخل ملفات ZIP، لحماية حسابك.
- أنشئ مفتاحًا جديدًا، ثم أضفه في Vercel باسم OPENAI_API_KEY.

خطوات النشر الضرورية:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى جذر مستودع GitHub (لا ترفع المجلد الخارجي نفسه).
3) افتح Vercel ثم Add New → Project، واختر مستودع GitHub.
4) من Project Settings → Environment Variables أضف:
   OPENAI_API_KEY = مفتاح OpenAI الجديد
   OPENAI_MODEL = gpt-4o-mini
   OPENAI_EMBEDDING_MODEL = text-embedding-3-small
5) اضغط Deploy.
6) بعد النشر افتح رابط موقعك ثم أضف /api/health للتأكد من أن الخدمة تعمل.

ملاحظة:
- لا تضع المفتاح داخل public/app.js أو أي ملف داخل public أو GitHub.
- لا تحتاج إلى تعديل الكود أو تغيير إعدادات Build يدويًا.
- التخزين في /tmp مؤقت للعرض التجريبي؛ الحسابات والجلسات والمستندات وسجل المحادثات
  قد تختفي بعد إعادة تشغيل Function أو نشر تحديث أو عند الانتقال إلى Function أخرى.
- لا ترفع ملف .env إلى GitHub. ملف .env.example مجرد نموذج أسماء إعدادات.
